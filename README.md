¡HOLA QUE TAL!
este proyecto tiene como objetivo principal, el desarrollar una Plataforma de Comunicación Interna y Gestión,
El software permite centralizar la comunicación de una empresa en un entorno seguro, estructurando las interacciones en dos grandes pilares:

1- Resolución de Problemas: Un canal donde los empleados abren hilos de consulta sobre dudas o fallas técnicas, y el equipo de soporte las gestiona hasta su resolución.
2- Interfaz de Usuario: se implementa mediante una consola interactiva basada en menús dinámicos (Scanner).
3- Capas de Entidades: Contiene las clases que representan la información del negocio (Usuarios, Preguntas, ect) y el enum, que restringen los estados del sistema.
